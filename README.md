# AI 行业每日热点追踪

每天梳理 AI 行业过去 24–72 小时内的重要动态，聚焦产品发布、融资并购、技术突破、行业规范四大方向，按重要性排序并附趋势点评。

## 文件命名

```
AI-industry-hotspots-YYYY-MM-DD.md
```

日期为整理当日北京时间。每条新闻包含标题、摘要与信息来源，文末附"今日趋势点评"与参考链接列表。

## 覆盖范围

1. **重要产品发布或功能更新**：OpenAI、Google、Anthropic、Meta 等公司动态
2. **融资事件与行业并购**：AI 基础设施、模型公司、AI for Science 等方向
3. **技术突破或重要论文**：前沿 benchmark、开源工作、独立实验室成果
4. **行业标准与规范动态**：AI 安全框架、数据治理、智能体互操作、监管进展

## 条目结构

- **标题**（日期 + 核心事件）
- **正文**（一句话摘要 + 必要的数字/时间补充）
- **来源**（发布主体 + 日期，尽量指向原始出处）
- **今日趋势点评**（2–3 段，跨条目提炼当日主线）
- **参考链接**（正文引用的所有 URL，完整可点击）
